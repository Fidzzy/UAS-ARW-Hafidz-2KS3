# UAS Analisis Runut Waktu (ARW) - Kelas 2KS3

Repositori ini berisi pengerjaan proyek akhir / Ujian Akhir Semester (UAS) untuk mata kuliah **Analisis Runut Waktu (ARW)**.

## Deskripsi Proyek
Proyek ini berfokus pada analisis data deret waktu (*time series data*), mencakup pemodelan statistik, evaluasi asumsi, hingga peramalan (*forecasting*) nilai di masa mendatang menggunakan R.
